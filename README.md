# 🚀 AutoTrading 관제탑 봇 (Hybrid Event-Driven Architecture)

한국투자증권(KIS) API와 텔레그램 HTS 원격제어를 결합한 완전 자동화 주도주 발굴 & 매매 플랫폼입니다. 이 봇은 마크 미너비니(Mark Minervini)의 7대 초강세장 템플릿과 윌리엄 오닐의 RS 스코어(상대강도)를 기반으로 전 세계 주도주를 자동 색출합니다.

## ✨ 핵심 기능 (Features)
1. **🇺🇸/🇰🇷 글로벌 주도주 스캐너**: 코스피/코스닥(300종목) 및 미국 S&P500(500종목) 데이터를 분석해 진정한 대장주만 색출. (매일 07:30 / 08:00 자동 스캔 후 캐시 및 물리 파일로 백업).
2. **📱 텔레그램 HTS 원격 제어**: 텔레그램 메신저 앱을 통해 스마트폰만으로 봇의 상태를 제어하고 대화형으로 소통합니다. (`/scan_kr`, `/scan_us`, `/portfolio`, `/stop`, `/resume` 등)
3. **🛡️ 유연한 보안 필터링**: 주도주 발굴 검색 기능은 불특정 다수(가족/외부 스터디원) 누구나 텔레그램 봇 메뉴를 사용할 수 있게 전면 개방되었으나, 내 계좌 열람(`/portfolio`)이나 매매 정지(`/stop`) 등의 민감한 명령은 **관리자로 지정된 본인 챗 아이디**가 아니면 시스템이 스스로 거부하도록 설계되었습니다.
4. **🧠 이벤트 기반(Pub/Sub) 아키텍처**: 모든 시스템 모듈이 `EventBus` 통신망을 통해 느슨하게 돌아갑니다. 매매 엔진과 텔레그램 응답부가 아예 분리 구동되어 서로 멈추는 병목 현상이 일절 없습니다. 동시 다발적인 검색명령 공격(디도스)도 자체적인 이중 스레드 락(Double Checked Locking) 캐시 메모리를 통해 원천 방어합니다.

## 🛠️ 설치 및 환경설정 (Quick Start)
### 1. 파이썬 환경 세팅
100% 퓨어 파이썬 가상환경 안에서 돌아가도록 구성되어 있습니다.
```bash
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install pandas pandas_ta FinanceDataReader requests schedule python-dotenv
```

### 2. .env 보안 파일 설정 (중요)
`config.py` 파일 내에 직접 키를 넣지 마세요!
리포지토리에 커밋된 `.env.example` 파일의 이름을 `.env` 로 바꾸신 다음 본인의 진짜 API 인증키와 텔레그램 봇 토큰을 입력하셔야 정상 작동합니다.

### 3. 터미널 실행 (원클릭 배치 스크립트)
```bash
.\run_main.bat  # 메인 관제탑 자동매매 엔진 종합 구동 파이프라인
.\run_test.bat  # 텔레그램 봇 및 스캐너 알고리즘 단독 호출 및 테스트 파이프라인
```
